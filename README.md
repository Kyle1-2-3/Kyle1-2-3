# Kyle

### Practical software for school life and everyday care.

I build projects around questions that come up in daily life: finding the right school information, making reminders easier to use, and deciding when software should ask a person for help.

My current work combines Python applications, structured data, and AI interfaces, with attention to the rules and failure cases behind the user experience.

## How these projects are built

- **Start with the interaction.** Make the next step clear for the person using the software.
- **Keep rules explicit.** Use structured records and application logic for dates, reminders, and state transitions.
- **Test the awkward cases.** Missing data, unclear replies, service failures, and conflicting schedules matter alongside the successful path.
- **Explain the limits.** Distinguish implemented behavior from what has been verified in real use.

I use AI tools during development and integrate models where they support the application. Each project README explains the model's role, the surrounding engineering, and the current limitations.
